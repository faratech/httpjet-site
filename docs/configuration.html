Running it

Configuration

httpjet's public configuration model is strict, versioned native TOML. It owns listener topology, runtime policy, cache behavior, PHP, observability, and optional integrations. LiteSpeed XML is retained as an explicit compatibility input for staged migrations; it is not the native deployment authority.

Native TOML

With no source option, httpjet loads /etc/httpjet/httpjet.toml. Use --config to select another native file. The schema requires config_version = 1, rejects unknown fields, resolves relative paths from the declaring file, and can load sorted per-vhost files with vhost_files.

SectionOwns
[server], [[listeners]], [[vhosts]]Server identity, listener/TLS topology, document roots, host routing, contexts, and per-vhost behavior.
[runtime.*]Workers, PHP-pool mode, page cache, TLS policy, memory trimming, and observability. Native runtime settings do not have equivalent operational serve flags.
[integrations.*]Optional Cloudflare request metadata, XenForo behavior, and LiteSpeed compatibility aliases. Native defaults are provider-neutral.
vhost_filesDeterministically merged per-vhost TOML files, convenient for configuration management and review.
minimal native configuration
config_version = 1

[server]
root = "/var/lib/httpjet"
name = "httpjet"
lsapi_user = "httpjet"
lsapi_group = "httpjet"

[[listeners]]
name = "http"
address = "127.0.0.1:8080"

[[vhosts]]
name = "example.test"
root = "/srv/example.test"
document_root = "/srv/example.test/public"

[vhosts.listener_domains]
http = ["example.test"]

[runtime.php]
disabled = true

Subcommands

SubcommandPurpose
serveBind the native listeners and serve the selected TOML configuration.
checkParse + lint the config without binding ports. check --strict is the deploy gate.
lsphpRun a standalone LSAPI pool defined by native PHP configuration.
config effectivePrint merged native configuration with secret values redacted.
config import, report, diffImport LiteSpeed XML to TOML, report directive support, and compare normalized models during a migration.

Validation, install, and reload

Install the reviewed TOML under /etc/httpjet, keep certificates and peer secrets outside source control, and validate as the service identity before enabling the unit.

CommandPurpose
httpjet --config … check --strictRequired preflight: strict schema, topology, integration requirements, and paths.
systemctl restart httpjetApply a full configuration or binary change through the service manager after a successful check.
systemctl reload httpjetApply only reloadable changes such as vhost, rewrite, access, expires, and tuning edits. Listener/TLS bindings, PHP-pool settings, and runtime policy require restart.

PHP / LSAPI

PHP is optional. Set runtime.php.disabled = false only when a configured [php] handler names an LSAPI-capable executable. Use runtime.php.socket when httpjet owns the pool, or runtime.php.external_socket when a separate httpjet lsphp systemd service owns it. The two modes are mutually exclusive.

Native mode does not install lsphp for you. Treat the PHP executable, its extensions, and its writable application paths as explicit deployment dependencies. FastCGI is not part of the version-1 native contract.

Page cache

The origin page cache is disabled by default. Configure runtime.page_cache to enable it, set the in-memory index and optional file-tier budgets, select cookie variation/private policy, and configure an optional per-vhost dictionary. Native apps opt responses in with X-HttpJet-Cache-Control; integrations.litespeed.cache_headers enables legacy aliases only when needed.

native page-cache policy
[runtime.page_cache]
enabled = true
memory_bytes = 134217728
admission_threshold = 2
store_path = "/var/cache/httpjet/page-cache" # optional file tier
hot_memory_bytes = 67108864

[runtime.page_cache.vhost_dictionaries]
"example.test" = "/etc/httpjet/dictionaries/example.test.dict"

LiteSpeed migration

Direct XML compatibility remains available through the 1.x series. Use it to inspect and compare an existing installation, then import a reviewable native candidate. Keep source XML until the imported behavior has been exercised; an import report is not a proof of directive-by-directive parity.

import and compare
httpjet config import --litespeed-root /path/to/litespeed \
  --output /tmp/httpjet.toml --report /tmp/httpjet-import-report.txt
httpjet --config /tmp/httpjet.toml check --strict
httpjet --config /tmp/httpjet.toml config effective
httpjet --config /tmp/httpjet.toml config diff --litespeed-root /path/to/litespeed

In XML mode, --litespeed-root selects the legacy parser and operational serve/lsphp flags remain available for isolated compatibility testing. The old --root spelling is deprecated. Do not add CLI overrides for native runtime policy.
