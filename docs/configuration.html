Running it

Configuration

httpjet is configured by a LiteSpeed-compatible XML tree selected with --root: conf/httpd_config.xml, the per-vhost files it references, and conf/mime.properties. An existing LiteSpeed/OpenLiteSpeed tree works as-is. On top of that compatible base, httpjet adds its own opt-in directives (throttling, geo/ASN ACLs, PROXY protocol, sub_filter, context overrides — marked httpjet below) which are ignored by LiteSpeed and absent from it.

The configuration tree

With no --root, httpjet uses /usr/local/lsws — the standard LiteSpeed location — so a drop-in deploy needs no flag at all. The parser (hj-config) applies LiteSpeed value semantics faithfully:

  • Variables $SERVER_ROOT, $HOSTNAME, $VH_ROOT, $VH_NAME substitute in both $VAR and ${VAR} forms.
  • Sizes accept K/M/G/B suffixes; times are bare seconds.
  • Bounded integers use OLS semantics: absent, unparsable, or out-of-range values fall back to the default (never clamped).
  • Booleans ("truthy") are 1, 2, or true (case-insensitive). Exception: followSymbolLink/allowSymbolLink accept only 1/true/2, where 2 (owner-restricted) fails closed to never-follow.
layout · a server root
/usr/local/lsws/
├── conf/
│   ├── httpd_config.xml      # server, tuning, listeners, vhosts, contexts
│   ├── mime.properties       # mime/type = ext1, ext2  (best-effort)
│   └── vhosts/example.test.xml   # per-vhost virtualHostConfig
└── logs/

Virtual hosts and contexts

Vhost declarations live in httpd_config.xml; per-vhost behavior in the referenced file's <virtualHostConfig>. allowSymbolLink is a tri-state override (file > declaration > server); restrained confines the vhost to vhRoot and forces symlinks off; an explicit <htAccess>allowOverride>0 kills the whole .htaccess chain even with autoLoadHtaccess.

Per-vhost <logging> httpjet gives each vhost its own error/access logs (useServer=0 + fileName), rolling at 50 MB with 30-day pruning by default; logHeaders nonzero (7 = combined) records request headers.

Contexts map URI prefixes to terminals and now carry per-context overrides httpjet:

Context directiveDefaultMeaning
maxReqBodySizeinheritPer-context body limit; 413 when exceeded on all terminals (static, LSAPI, proxy).
responseTimeoutinheritBackend response timeout override, seconds (proxy paths only).
bandwidthLimit0Per-context egress throttle (bytes/s) — overrides the server-wide <tuning> rate.
subFilter (repeatable)—SEARCH => REPLACEMENT literal response-body substitution (nginx-shaped). The => separator is mandatory — a rule missing it disables the whole context's sub_filter with a warning.
subFilterOnce / subFilterTypes / subFilterMaxBody0 / text/html / 4MFirst-occurrence-only; eligible Content-Types; buffering cap — a stream past the cap passes through raw, never half-filtered.
cachePolicy/*onThe six LSWS gates (checkPublicCache, checkPrivateCache, respectCacheable, enableCache, enablePrivateCache, enablePostCache) enforced on both cache tiers; microCache5xx httpjet adds 5xx micro-caching.

Subcommands and serve flags

There are four subcommands. The default (no subcommand) is check.

SubcommandPurpose
check [--strict]Parse and print a configuration summary without binding ports. --strict lints topology (shared docroots, missing www. twins, unmapped vhosts) and also hard-errors on a missing vhost docroot. Prints inert-config warnings (geo lists without a db, auth directives without Require, …). The deploy gate.
serveBind the configured listeners and serve.
lsphpRun a standalone, persistent lsphp pool (the zero-downtime deploy half). See LSAPI & PHP.
lsphp-reloadAsk a running pool supervisor to replace its worker generation without closing the systemd-owned listener.

!
Removed flags

--cache-peer / --cache-peer-fill* (cross-node page-cache peers) were removed in August 2026 — the loopback purge endpoints remain, but no peer machinery parses anymore. --io-uring never exists: the io_uring transport is unconditional.
