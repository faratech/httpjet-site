Configuration reference

httpjet is configured by a LiteSpeed-compatible XML tree selected with --root: conf/httpd_config.xml, the per-vhost files it references, and conf/mime.properties. An existing LiteSpeed or OpenLiteSpeed tree works as-is. On that base httpjet layers its own opt-in directives — marked httpjet — which LiteSpeed ignores. Operational overrides live on the command line, not in the XML.

The configuration tree

With no --root, httpjet uses /usr/local/lsws. The parser (hj-config) applies LiteSpeed value semantics faithfully:

  • Variables $SERVER_ROOT, $HOSTNAME, $VH_ROOT, $VH_NAME (plus $DOC_ROOT and $VH_DOMAIN once the vhost resolves them) substitute in $VAR and ${VAR} forms.
  • Sizes accept K/M/G/B suffixes; times are bare seconds.
  • Bounded integers use OLS semantics: absent, unparsable or out-of-range values fall back to the default (never clamped). The isolation modes setUIDMode/chrootMode are the exception: out-of-range is a hard error (2026-09-16).
  • Booleans are 1, 2 or true (case-insensitive); followSymbolLink/allowSymbolLink treat 2 (owner-restricted) as fail-closed never-follow.
  • Unknown elements are ignored so real trees load; check warns on the ones that would silently do nothing, and security-relevant ones httpjet cannot enforce (a partial allowOverride mask, vhost clientVerify, rewrite maps, phpIniOverride, enableHotlinkCtrl, forceStrictOwnership) refuse the load.
layout · a server root
/usr/local/lsws/
├── conf/
│   ├── httpd_config.xml          # server, tuning, security, listeners, extProcessors, vhost declarations
│   ├── mime.properties           # mime/type = ext1, ext2   (best-effort)
│   └── vhosts/example.test.xml   # <virtualHostConfig>: docroot, contexts, rewrite, vhssl, cache, logging
└── logs/

Listeners and TLS

DirectiveDefaultMeaning
name, address*:80ip:port / host:port. httpjet also unix:/path or uds:/path for an HTTP-over-Unix-socket listener (TLS over UDS is unsupported: check warns and the TLS half does not serve). Listener names are the stable identity across reloads.
secure, keyFile, certFile, certChainoffTLS material; certChain=1 appends CACertFile to the served chain.
CACertFile · clientVerify · verifyDepthnone · 0 · 1Client-certificate verification (0 none · 1 optional · 2 required · 3 optional without CA) against the listener CA.
crlFile httpjetnonePEM CRL/bundle enforced by the client verifier.
enableStapling0Compatibility only; OCSP needs --features ocsp + --ocsp-responder.
proxyProtocol httpjet0PROXY v2/v1 required on this listener; fail-closed; never on a public bind.
vhostMapList/vhostMap vhost, domain—Host→vhost; domains lowercased; a configured :port is ignored and a leading www. is stripped for the lookup key. Resolution is exact match, then the nearest configured parent domain (a.example.com → example.com, treated as a non-canonical foreign host), then the bare * catch-all. Glob patterns such as *.example.com or example.* are not supported: check warns and they never match.

    <certFile>/etc/letsencrypt/live/example.test/fullchain.pem</certFile>
    <clientVerify>0</clientVerify>
    <vhostMapList><vhostMap><vhost>example.test</vhost><domain>example.test,www.example.test</domain></vhostMap></vhostMapList>
  </listener>
</listenerList>

External processors

An <extProcessor> (server-level <extProcessorList> or per-vhost) is a reverse-proxy upstream (proxy), an LSAPI app (lsapi), or httpjet a FastCGI app (fcgi/fastcgi). <phpConfig> configures the default PHP handler with the same pool knobs. Unknown legacy types (rails, appserver, …) keep proxy behavior; cgi contexts are not executed.

Virtual hosts

Declarations live in httpd_config.xml (name, vhRoot, configFile, allowSymbolLink, enableScript, restrained); behavior lives in the referenced <virtualHostConfig>. allowSymbolLink is a tri-state override (file > declaration > server); restrained confines the vhost to vhRoot and forces symlinks off; enableScript=0 disables script handlers for the vhost.

Vhost directiveMeaning
docRoot, indexFiles, enableExpires/expiresByTypeRoot and per-vhost overrides of the server settings.
<rewrite> enable, autoLoadHtaccess, base, rulesInline rules run before the .htaccess chain.
<htAccess> allowOverride, accessFileNameOnly allowOverride 0 (no .htaccess) or 31 (all categories) loads per vhost; a partial category mask refuses the load (the server-level block accepts only 31). The access file name defaults to .htaccess.
<vhssl> keyFile, certFile, certChain, CACertFileThe SNI identity for this vhost's domains (chain material, not a client-verify root).
<cache> enableCache, enablePublicCache, enablePrivateCachePer-vhost page-cache gates (with --page-cache-standard-vhosts a missing block gets a default public policy).
<scriptHandlerList><scriptHandler> suffix, type, handlerSuffix routing to lsapi/php handlers or a cgi handler bound to a FastCGI processor.
<websocketList><websocket> uri, addressWebSocket relay maps (plain TCP HTTP/1 upstreams).
<logging> accessLog/errorLog with useServer=0, fileName, rollingSize, keepDays, logHeaders httpjetPer-vhost log files (default roll 50 MB, keep 30 days; logHeaders default 3 = combined, 7 = combined + Host). Log paths are boot-owned.

Contexts

Contexts map URI prefixes to terminals (static, proxy, redirect, php/lsapi via handler) and carry per-context overrides:

Context directiveDefaultMeaning
type, uri, location, handler, enabled—Kind, prefix, on-disk location (static), processor name (proxy/lsapi).
extraHeaders—Additional response headers for the context: Name: value lines only (header operations refuse the load); NONE sets none and stops inheritance. Not allowed on proxy contexts (load error).
addDefaultCharset / addDefaultCharsetCustomizedoffCharset appended to text types.
cachePolicy/*on (enablePostCache off)checkPublicCache, checkPrivateCache, respectCacheable, enableCache, enablePrivateCache, enablePostCache — the six LSWS gates, enforced on both cache tiers.
maxReqBodySize httpjetinheritPer-context body cap (413) on every terminal.
responseTimeout httpjetinheritUpstream response-head deadline, seconds (proxy paths).
bandwidthLimit httpjet0Egress throttle overriding the server-wide rate.
subFilter (repeatable) · subFilterOnce · subFilterTypes · subFilterMaxBody httpjet— · 0 · text/html · 4MSEARCH => REPLACEMENT literal body substitution. The => separator is mandatory — a rule missing it disables the whole context's sub_filter with a warning. →
vhost XML · a proxied API prefix with overrides
<contextList>
  <context>
    <type>proxy</type>
    <uri>/api/</uri>
    <handler>application</handler>
    <maxReqBodySize>2M</maxReqBodySize>
    <responseTimeout>15</responseTimeout>
    <subFilter>http://internal.example => https://example.test</subFilter>
    <subFilterTypes>text/html,application/json</subFilterTypes>
  </context>
</contextList>

Checking a configuration

check
httpjet --root /abs/root check            # summary: listeners, vhost map, fast-memo verdicts, warnings
httpjet --root /abs/root check --strict   # same lint output; exits non-zero on lint errors (warnings never fail)

Run the check under the intended service identity as well as as root: readable-by-root is not proof the runtime user can read certificates or write logs and sockets. The same normalization runs for the write API's in-memory bundle (parse_bundle), which additionally refuses DTDs, more than 64 nesting levels, more than 128 vhosts, and 1 MiB of XML. A config file read from disk is capped at 16 MiB per file (ConfigError::TooLarge, 2026-10-06) — a bound on all readers, check included.

Environment variables

The full list, with the flags they pair with, is on the CLI reference. The ones most often set in a unit drop-in: HTTPJET_ACCESS_LOG_FORMAT=json, HTTPJET_ERROR_LOG_FORMAT=json, HTTPJET_SYSLOG_TARGET, CF_SEND_ZSTD=1, HJ_FAST_MEMO=0, HTTPJET_OTEL=1, RUST_LOG.
