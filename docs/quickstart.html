Quickstart

Native, versioned TOML is httpjet's public configuration model. This walks from a source checkout to a running static origin: build the binary, copy the neutral example, validate it, and serve. LiteSpeed XML remains an explicit compatibility and migration input, not the default deployment model.

Prerequisites

  • Linux with usable io_uring support, plus a C toolchain for the crypto and allocator dependencies.
  • Rust 1.97 (edition 2024) for a source build. Public binary packages are being prepared; until then, build from the checkout.
  • Only for PHP: an LSAPI-capable lsphp executable supplied by the operator. Static and reverse-proxy deployments do not need PHP or a LiteSpeed installation.
i
Release status

The repository does not yet publish signed installable binaries or distribution packages. Treat this guide as the source-install path; do not use deployment-specific scripts as a general installer.

Build the binary

A debug build is fine for iteration. Use a normal release build for local serving and reproducible tests. The checked-in PGO helper is tailored to one deployment and is not a general release-build command.

build · cargo
# debug build — fast to compile, ~5x slower at runtime
cargo build -p httpjet

# release build (REQUIRED for any benchmarking)
cargo build --release -p httpjet  # → target/release/httpjet

The workspace is large (1 binary + 14 hj-* libraries), so when iterating on one crate, scope the build and tests with -p, e.g. cargo test -p hj-rewrite.

Create and validate a native config

Copy the neutral example and its vhost file, then set the listener address, domain, and document root for your machine. Native paths are resolved relative to the TOML file that declares them.

check · config lint
mkdir -p /tmp/httpjet/vhosts /srv/example.test/public
cp examples/httpjet.toml /tmp/httpjet/httpjet.toml
cp examples/vhosts/example.toml /tmp/httpjet/vhosts/example.toml
printf 'hello from httpjet\n' > /srv/example.test/public/index.html

# edit /tmp/httpjet/vhosts/example.toml for your domain and document root, then:
./target/debug/httpjet --config /tmp/httpjet/httpjet.toml check --strict

Run it — for development

The supplied example is HTTP-only on 127.0.0.1:8080 with PHP and the page cache disabled. It is intentionally safe to run alongside an existing server. Native runtime policy belongs in TOML, so operational flags after serve are rejected.

serve · dev (alt ports)
./target/release/httpjet --config /tmp/httpjet/httpjet.toml serve
!
Keep test state isolated

Use alternate HTTP/HTTPS/metrics ports, a separate PHP socket if PHP is enabled, and a separate page-cache root. Do not bind a test instance to a service manager's production listeners.

Verify

Fetch the example page. The page cache is off in the neutral starter configuration; when you later enable it, native applications use the X-HttpJet-* cache protocol. LiteSpeed header aliases require an explicit compatibility profile.

verify · curl
curl -i -H 'Host: example.test' http://127.0.0.1:8080/

# after enabling a cacheable native application response, inspect:
curl -I -H 'Host: example.test' http://127.0.0.1:8080/ | grep -Ei 'x-httpjet-cache|cache-status'
