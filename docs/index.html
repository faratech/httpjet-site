What httpjet is

httpjet is a full origin server on a memory-safe, observable Rust core. Its public model is provider-neutral: native TOML describes the deployment, while optional profiles add application, proxy, or LiteSpeed-compatibility behavior only where required.

  • Loads strict native TOML with versioning, per-vhost files, validation, redacted effective output, and deterministic merges.
  • Imports and compares LiteSpeed XML when migrating an existing installation.
  • Speaks the native LSAPI wire protocol to a configured lsphp executable (no FastCGI shim in the version-1 contract).
  • Evaluates the same .htaccess rewrite rules, access control, and header directives.
  • Serves HTTP/1.1, a from-scratch HTTP/2 stack, and HTTP/3 over QUIC, with optional client-certificate verification.
  • Provides an opt-in origin page cache driven by native X-HttpJet-* headers, with optional LiteSpeed aliases.

Public beta preparation

The source tree includes neutral examples and generic systemd units. Signed public binary packages, installer UX, and a supported-platform matrix are the next release work; see Operations.

Why it exists

Migration compatibility remains useful for existing LiteSpeed installations, but it should not leak into a new deployment's design. Native TOML keeps runtime policy reviewable, makes optional integrations explicit, and removes the need to encode application behavior in command-line flags or legacy configuration files.
