httpjet

A from-scratch Rust web server that is a drop-in LiteSpeed replacement: it reads the same conf/httpd_config.xml tree, speaks native LSAPI to lsphp, evaluates the same .htaccess files, and adds native HTTP/2 and HTTP/3, reverse-proxy and FastCGI gateways, an opt-in LSCache-protocol page cache, optional ACME and OCSP, and a loopback admin API — all on one io_uring transport.

What httpjet is

httpjet is a complete origin server on a memory-safe Rust core, built so that an existing LiteSpeed Web Server (LSWS 6.3.5 compatibility target) or OpenLiteSpeed deployment becomes an httpjet deployment by pointing --root at the tree it already has. Compatibility is the feature; everything httpjet adds on top is an explicit opt-in that LiteSpeed simply ignores.

Compatible surface

  • LiteSpeed XML: server, tuning, listeners, vhosts, contexts, mime.properties
  • Native LSAPI wire protocol to any LSAPI-capable lsphp
  • mod_rewrite, access control, Basic auth, Header, ErrorDocument, LSCache directives
  • LSCache protocol (X-LiteSpeed-Cache-Control / -Tag / -Vary / -Purge)
  • LiteSpeed fileETag=28 ETags, .html→PHP dispatch order

httpjet-native (opt-in)

  • Per-client throttle, GeoIP/ASN rules, PROXY protocol, Unix-socket listeners
  • Weighted upstream groups with active health checks; h2:// / h2s:// upstreams; FastCGI
  • Per-context body/timeout/bandwidth overrides, sub_filter, request decompression
  • ACME HTTP-01/DNS-01, OCSP stapling, kTLS/sendfile, OpenTelemetry
  • Loopback status + transactional config API, WAF sidecar, compile-time extensions
i
Where it runs

httpjet serves WindowsForum.com on an x86_64 origin and MoonTimeNow.com + ThisDayInHistory.ai on an active ARM64 origin behind Cloudflare, over the pure io_uring transport with the page cache's file tier live. It is early-stage software (semantic version 0.1.10, Rust 1.99.1+, edition 2024, GPL-3.0-only) built around these production deployments — test on alternate ports before trusting it elsewhere. See Capabilities & limits for the honest matrix.

Project status

AspectState (2026-10-26)
Version0.1.10 (current production release; see the latest public release) — semantic versioning adopted 2026-09-17; MSRV Rust 1.99.1, edition 2024; dependencies current (0.1.x sweep: tokio 1.54, rustls 0.23.46, rustls-webpki 0.103.16 + webpki-roots 1.0.11, fancy-regex 0.20, parking_lot 0.13, zstd 0.14.3).
ConfigurationLiteSpeed-compatible XML is the authority; httpjet-native directives are opt-in add-ons. check --strict is the deploy gate.
TransportPure io_uring (monoio) for H1/H2/H3 — the only transport; there is no epoll fallback and no Windows/macOS port.
PHPNative LSAPI; the operator supplies lsphp. Production runs the persistent external pool with zero-downtime generation reloads.
Page cacheOff by default; LSCache-protocol opt-in, private tier, per-URL cookie vary, tmpfs file tier, per-vhost dictionaries, generation-scoped namespaces. Live in production.
Optional featuresacme, ocsp, otel, ktls, profiling — build features that still need explicit runtime opt-in.
Security postureWhole-codebase review rounds through 2026-10-23 landed, plus the October bug-bash campaign (rounds 1–16 across 0.0.6–0.1.1, then a five-round review in 0.1.10 that closed 23 issues; see audit posture); fail-closed defaults throughout.
ReleaseThe Linux installer and signed DEB, RPM and static archives are available through GitHub Releases. The full distribution matrix was not completed for the current release.
